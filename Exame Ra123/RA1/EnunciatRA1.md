# RA1 — Dues pàgines HTML enllaçades (Festival del Vent)

## Context

Aquest exercici avalua continguts bàsics de **HTML** treballats a la carpeta `02-Web`, especialment:

- creació de noves pàgines HTML
- enllaços entre fitxers del mateix projecte
- ús correcte de títols i llistes

Se't proporciona un fitxer `index.html` inicial. Has de completar-lo i crear una nova pàgina anomenada `activitats.html`.

---

## Objectiu

Has de construir una petita web del **Festival del Vent** formada per **dues pàgines HTML enllaçades entre si**.

Cal treballar únicament amb HTML.

`No` es permet CSS.  
`No` es permet JavaScript.

---

## Estructura del projecte

```text
RA123-2026D/RA1/
├── index.html
└── activitats.html
```

---

## Tasca

Has de completar l'activitat fins que compleixi les **5 comprovacions objectives** d'aquest enunciat.

Cada comprovació correcta suma **2 punts**.  
La nota màxima d'aquest RA és **10 punts**.

---

## Elements que han de quedar correctes

1. A `index.html`, el títol principal (`h1`) ha de ser exactament **"Festival del Vent"**.
2. A `index.html`, hi ha d'haver un enllaç funcional cap al fitxer **`activitats.html`** amb el text **"Veure activitats"**.
3. S'ha de crear el fitxer **`activitats.html`** com a document HTML5 correcte, amb el títol de pestanya **"Activitats - Festival del Vent"**.
4. A `activitats.html`, hi ha d'haver una **llista no ordenada** amb exactament aquests 3 elements:
   - `Tallers d'estels`
   - `Vol de cometes`
   - `Exposició fotogràfica`
5. A `activitats.html`, hi ha d'haver un enllaç funcional de tornada a **`index.html`** amb el text **"Tornar a l'inici"**.
